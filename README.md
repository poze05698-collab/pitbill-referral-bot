# 🤖 Bot de Indicações V2

Bot desenvolvido em Python utilizando pyTelegramBotAPI e SQLite.

## Recursos

- 👤 Cadastro automático
- 💰 Sistema de saldo
- 👥 Sistema de indicações
- 💳 Cadastro de Pix
- 💸 Sistema de saques
- 👑 Painel do administrador
- 🏆 Ranking
- 📜 Histórico
- 🛡️ Sistema antifraude

---

## Instalação

Clone o projeto:

```bash
git clone https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
```

Entre na pasta:

```bash
cd BotIndicacoesV2
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

---

## Configuração

Abra o arquivo:

```
config.py
```

Configure:

```python
TOKEN = "TOKEN_DO_BOT"

ADMIN_ID = 123456789

GRUPO_ID = -100xxxxxxxxxx

GRUPO_LINK = "https://t.me/SeuGrupo"
```

---

## Executar

```bash
python bot.py
```
