# 🚀 Titan Affiliate Platform (TAP)

## Sobre

Titan Affiliate Platform é uma plataforma profissional de afiliados, gamificação e gestão de comunidades para Telegram.

O projeto foi desenvolvido utilizando uma arquitetura modular, preparada para crescimento, escalabilidade e integração com futuras aplicações Web e Mobile.
